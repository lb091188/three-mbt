# three-native

**three.js for MoonBit, on WebGPU — 3D scenes embeddable in native desktop apps.**

**基于 WebGPU 的 MoonBit 版 three.js——3D 场景可直接嵌入原生桌面应用。**

- GPU 后端:[wgpu-mbt](https://mooncakes.io/docs/#/Milky2018/wgpu_mbt/)(wgpu-native,链接 Vulkan / Metal / D3D12)
- 桌面集成:[moonbit-libyue](https://github.com/lb091188/moonbit-libyue)(3D 视图与原生控件混排)
